# 📊 Projeto Excel - Organizador de Imposto de Renda

## 📌 Sobre o Projeto

Este projeto foi desenvolvido durante o curso da **DIO**, com o objetivo de aplicar na prática os conhecimentos adquiridos nas aulas de Excel.

A proposta foi criar uma **ferramenta no Excel para auxiliar na organização das informações necessárias para a declaração do Imposto de Renda**.

A planilha funciona como um agregador de informações, permitindo registrar e organizar dados de forma prática, utilizando recursos de validação, navegação, fórmulas e funcionalidades do Excel.

---

## 🎯 Objetivo

O principal objetivo do projeto foi desenvolver uma ferramenta que facilitasse o controle e a organização das informações utilizadas na declaração do Imposto de Renda.

Além disso, o projeto permitiu colocar em prática conceitos como:

- Organização de dados;
- Criação de tabelas;
- Utilização de fórmulas;
- Validação de dados;
- Filtros;
- Formatação condicional;
- Referências de células;
- Navegação entre informações;
- Automatização de processos dentro do Excel.
